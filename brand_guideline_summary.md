# Shea's Snacklaces — Complete Brand & Store Specifications

## 1. Brand Overview
- **Brand Name**: Shea's Snacklaces
- **Founder**: Shea (Age 7, "Snack Boss" / "Snack CEO")
- **Mission**: Make snack time feel like playtime for kids and grown-ups alike with tasty, wearable treats.
- **Core Taglines**:
  - *"Wear It. Snack It. Love It."*
  - *"Fun to Wear. Even Better to Eat."*
  - *"Snacks You Wear. Then Eat."*
- **Voice Pillars**: Playful • Simple • Kid-Powered • Silly-Smart • Genuine
- **The Golden Rule**: If a 7-year-old and their grandparent can both read a line and smile, it's on-brand.

## 2. Visual Identity & Design System

### Color Palette
| Color Name | Hex Code | Usage & Allocation |
| :--- | :--- | :--- |
| **Sunshine Yellow** | `#FFC923` | **Dominant Background (~60%)** — Brand canvas / "party tablecloth" |
| **Snack Coral** | `#F05534` | **Headlines, CTAs, Accents (~15-20%)** — Energetic buttons & badges |
| **Twist Teal** | `#0CBFA5` | **Brand lockups, secondary headers, links (~10-15%)** |
| **Pretzel Gold** | `#FFAD00` | **Icons, bead accents, highlight details (~5%)** |
| **Toasty Brown** | `#7E4910` | **Pretzel art, sticker borders, grounding text/outlines (~5%)** |

### Typography
- **Headlines / Display**: `Fredoka` (Alternatives: `Baloo 2`, `Chewy`) — Bold, rounded, bubbly, Title Case / ALL CAPS, thick outlines.
- **Body / Readable Text**: `Quicksand` or `Poppins` — Clean, rounded, friendly sentence case.

### UI & Graphic Style
- **Confetti Sprinkles**: Scattered teal, coral, and gold sprinkles across Sunshine Yellow fields.
- **Outlines**: Thick cartoon-sticker outlines (`#7E4910` or dark brown/black).
- **Cards & Badges**: Soft pill shapes, rounded corners (`border-radius: 20px - 28px`), sticker effect drop-shadows (`box-shadow: 0 6px 0 rgba(0,0,0,0.15)`).
